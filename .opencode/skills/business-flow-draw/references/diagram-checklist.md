# 验收清单与排错（通用）

改完图后**逐条走**。硬门槛不过 = 不合格，禁止交付。

## 一、🔴 硬门槛（机器判定，必须全过）

### 1. 生成成功

```
wrote ... N nodes, M edges
```
- `M`（edges）必须 **> 0**；等于 0 说明连线没写进去
- `N`（nodes）必须 > 0

### 2. 几何校验全 0

```powershell
python3 <drawio-skill>\scripts\validate.py <图路径> --score
```

期望：`0 error(s), 0 warning(s)` 且 `score: 0 (0 through-vertex, 0 crossings, 0 overlaps)`

| 报错 | 含义 | 修法 |
|---|---|---|
| `W-EDGE-CROSS` | 两条边交叉 | 给其中一条加/调 `pts=[...]` waypoints，**靠反复跑校验迭代，不要手工证明不交叉** |
| `W-EDGE-THROUGH-VERTEX` | 边直穿某个方框 | 加 waypoints 绕开 |

### 3. 文字与重叠自检

```powershell
python3 <本skill>\scripts\check-diagram.py <图路径>
```

期望：`OK: 无标签溢出、无同层重叠`

| 报错 | 含义 | 修法 |
|---|---|---|
| `TALL 高60 需78` | 文字装不下（会截断） | 加大框高/宽，或缩短文案 |
| `WIDE 宽200 文本240` | 单行超宽 | 同上 |
| `OVERLAP parent=x a b` | 同层盒子重叠 | 挪开坐标 |

> ⚠️ `check-diagram.py` 的文字宽度是**估算**（CJK≈`fontSize`、ASCII≈0.55×、行高1.35×、内边距14px），
> 未对真实渲染校准。可能误报也可能漏报 —— 所以下面的人工检查不能省。

## 二、🟡 软检查（人工/AI 判定，判据如下）

### A. 业务设计说明书里的"核心信息"是否一眼可读

**判据**：拿说明书 **§1《核心信息》**（读者必须一眼看懂的 2-3 条）反问新读者，逐条能对着图答上即过——章节名以说明书模板为准。

### B. 表达禁则无违反

**判据**（通用禁令，业务说明书可追加）：
- [ ] 图上搜不到：接口路径、类名、框架名、Filter、Handler、Token 字样
- [ ] 说明书里标为"必须独立"的判断，图上确实是**两个不同的 mxCell**
- [ ] 多个入口都指向**同一个**核心容器（没有画成多个重复的中心）

### C. 文档同步

- [ ] 业务有变动 → 更新业务设计说明书 + 其变更记录
- [ ] 新增/删除节点或连线 → `gen-*.py` 是权威，无需回填清单

## 三、排错表

| 现象 | 原因 | 修法 |
|---|---|---|
| 反复 `The previous response was interrupted` / `stream ended without finish_reason` / 单轮跑满 ~300 秒且无工具调用 | **单轮输出过大**：一次写完整个 `gen-*.py`，或在推理里手工验算坐标/交叉/文字宽度，撞上游约 300s 流上限，整轮作废、零产出。**若症状出现在第一笔 write 之前**，病因是在推理里先做全图设计（布局/坐标/配色/节点清单）而非写入超长 | 按 SKILL.md「骨架+分批写入」重来：首笔只写骨架，分批（≤10 元素/批）补内容、每批跑校验；**第一笔 write 之前不做任何业务设计**，直接发骨架 write，设计推迟到批次内；**不要重试同样的全量写法** |
| `KeyError` / `NameError` | **删了节点但没删引用它的 `edge(...)`**，或变量名拼错 | 恢复该节点，或删掉对应 `edge` 行 |
| 生成日志 `0 edges` | `edge()` 函数体漏了 `edges.append(...)` | 检查其末尾是否为 `edges.append(e + '</mxGeometry></mxCell>')` |
| 生成日志 `0 nodes` | `node()` 漏了 `cells.append(...)` | 同上检查 |
| 换行变成空格/乱码 | 用了 `escape()` 而非自定义 `esc()`，`&#xa;` 被转义成 `&amp;#xa;` | 统一用 `esc()` |
| `python3` 不是内部命令 | Windows 常只有 `python` | 复制 `python.exe` 为 `python3.exe` 即可（skill 文档要求用 `python3`） |
| 校验通过但图看着不对 | 校验只查几何，不查业务语义、不查与源一致性 | 走 🟡 软检查；并确认没有手改过 `.drawio` |

## 四、为什么必须两层

- **硬门槛**：机器证明"没有客观缺陷"（线不交叉、字不溢出）
- **软检查**：人证明"画的是对的东西"（业务符合说明书）

校验全过 **≠** 图没问题：机器不校验业务语义、不校验与源脚本一致、不校验美观度。
