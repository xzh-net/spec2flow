# 画图规范（通用）

适用于本 skill 生成的所有 `.drawio`。具体某个图的坐标与文案见该项目的 `gen-*.py`。

## 一、线型语义（图例必备）

| 线型 | 写法 | 用途 |
|---|---|---|
| 实线（深色 `#333333`） | `endArrow=block` | 正常业务流 |
| 红虚线（`#b85450`） | `dashed=1` | 拒绝、失败、提示、更换账号等**异常/回退**路径 |
| 绿线（`#82b366`） | 实线 | **通过**、成功、到达目标 |
| 灰虚线（`#666666`） | `dashed=1;endArrow=open` | 查询数据库 / 缓存等**数据读写**（非业务流） |

**图例规则**：使用 3 种及以上语义色时必须加图例——图例规格见本文件的"线型语义"表；成品图例样例见 `docs/diagrams/gen-iam-flow.py` 的"图例"段（checklist 不含图例模板）。

## 二、配色（语义色，不是装饰色）

| 语义 | fillColor / strokeColor |
|---|---|
| 正常流程 / 应用入口 | `#dae8fc` / `#6c8ebf` |
| 成功 / 目标达成 | `#d5e8d4` / `#82b366` |
| 决策判断（中性） | `#fff2cc` / `#d6b656` |
| **拒绝 / 错误** | `#f8cecc` / `#b85450` |
| **警告 / 需人工干预** | `#ffe6cc` / `#d79b00` |
| 系统核心容器（如认证中心） | 头 `#e1d5e7`、体 `#fbf9fd` / `#7b4bb5` |
| 数据库 / 缓存 | `#ffffff` / `#666666`（`shape=cylinder3`） |
| 说明便签 | `#fff2cc` / `#d6b656`（`shape=note`） |

**注意**：两个语义不同的容器**不要共用同一填充色**；若必须同色，靠描边粗细 + 标题文字区分，并在业务说明书中写明。

## 三、走线约束（硬规则）

1. **菱形（rhombus）进出必须锚在顶点**：上 `exitX=0.5;exitY=0`、下 `0.5;1`、
   左 `0;0.5`、右 `1;0.5` —— 走侧边中点会穿模
2. **平行线间距 ≥ 40px**；拐角到目标的最后直线段 **≥ 20px**（否则箭头压住拐角）
3. **容器内子节点 = 相对坐标**（相对容器左上角）；**连线 waypoint = 页面绝对坐标**
   （连线 `parent="1"`）。换算：`绝对 = 容器原点 + 相对值`
4. **长回环一律用显式 waypoints 固定路径**，不要指望路由器自己绕开障碍
5. 容器/泳道标题**不要左对齐压在走线通道上**（会挡线）
6. 一个节点有 2+ 条连线时，**必须**用 `exitX/entryX` 分散锚点，避免叠线
7. 手工排布节点**不超过 15 个**；超过改用 `drawio-skill` 的 `autolayout.py` 布局

## 四、标签

- 换行用 `&#xa;`，**不能用 `\n`**（XML 属性里会被吞成空格）
- 转义用 `xml.sax.saxutils.escape` 后要**还原 `&amp;#xa;` → `&#xa;`**，否则换行失效
- 边标签只放短词（`通过` / `拒绝` / `未登录`）；长解释放节点或便签
- 文案必须能在框内放下 —— 用 `scripts/check-diagram.py` 静态检查

## 五、XML 骨架（来自 drawio-skill，此处仅速查）

- 根：`mxfile → diagram → mxGraphModel → root`
- root 必须有 `id="0"` 和 `id="1"`，用户图形从 `id="2"` 起
- **每条边必须带** `<mxGeometry relative="1" as="geometry"/>`，自闭合边不渲染
- 所有文字样式带 `html=1`
- 完整 XML 规则、样式词汇库、形状搜索见全局 `drawio-skill` 的文档
